# ضفاف العربية

**منصة مسابقات مباشرة بين الفصول في اللغة العربية — مدرسة يزيد بن حاتم الأزدي**

برنامج تربوي ثقافي يحتفي باللغة العربية من خلال منافسات حيّة بين الفصول في: النحو والصرف، والبلاغة، والأدب، والإملاء، والقراءة. الفئة المستهدفة: طلاب الصفوف من التاسع إلى الثاني عشر.

يجيب الطلاب من هواتفهم، وتظهر الأسئلة والنتائج لحظة بلحظة على شاشة العرض (جهاز الإسقاط)، ويدير المعلم كل شيء من لوحة التحكم.

<a id="features"></a>
## 1) ما الذي يقدمه الموقع؟

| الصفحة | الرابط | الوصف |
|---|---|---|
| الافتتاح والصفحة الرئيسية | `/` | زر «افتح الموقع»، ثم رسالة ترحيب وأهداف البرنامج مع احتفال صغير، ثم الصفحة الرئيسية |
| عن البرنامج | `/about` | الفكرة، والأهداف، ومجالات المنافسة، والفئة المستهدفة، وأشكال المسابقات |
| الطالب | `/play` | يختار الطالب صفه ثم فصله ويكتب اسمه، فينضم تلقائيًا إلى مسابقة فصله |
| شاشة العرض | `/display` | السؤال والعدّاد، وعدد من أجاب، وتوزيع الإجابات، ولوحة الصدارة، وشجرة البطولة، ورمز QR للانضمام |
| لوحة التحكم | `/admin` | الفصول والأسئلة، والدوري والجولات، والتحكم المباشر، والإحصائيات، والإعدادات |

**نوعان من المسابقات:**

- **دوري خروج المغلوب:** يُنشأ جدول المباريات تلقائيًا (حسب الصف أو بالقرعة)، ويتأهل الفائز حتى يُتوَّج البطل.
- **مسابقات منفصلة للفصول:** يجيب كل فصل عن جميع أسئلته، ويمكن تشغيل عدة فصول في الوقت نفسه، وكل طالب ينتقل إلى سؤاله التالي فور إجابته.

يعمل الموقع **بلا إنترنت** داخل شبكة المدرسة (الخطوط ومكتبة الاتصال مضمّنة فيه)، ويحتاج الإنترنت مرة واحدة فقط عند التشغيل الأول لتنزيل المتطلبات.

<a id="windows"></a>
## 2) التشغيل على ويندوز (الأسهل)

1. ثبّت **Python 3.12** من الموقع الرسمي: <https://www.python.org/downloads/>
   - مهم: أثناء التثبيت فعّل خيار **Add python.exe to PATH**.
2. نزّل مجلد المشروع إلى الجهاز (مثلًا من GitHub: زر **Code** ثم **Download ZIP**، ثم فك الضغط).
3. انقر نقرًا مزدوجًا على الملف **`start.bat`**.
   - في المرة الأولى سيُنزّل المتطلبات (يحتاج إنترنت، دقيقة تقريبًا).
   - سيفتح المتصفح تلقائيًا على `http://localhost:8000/`.
4. **اترك النافذة السوداء مفتوحة** طوال المسابقة؛ إغلاقها يوقف الموقع.

> إذا ظهرت رسالة من **جدار حماية ويندوز (Windows Firewall)** فاضغط «السماح» (Allow) للشبكات **الخاصة**، وإلا فلن تتمكن هواتف الطلاب من الدخول.

**التشغيل اليدوي (بديل):** افتح موجه الأوامر داخل مجلد المشروع واكتب:

```bat
py -3 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

<a id="mac"></a>
## 3) التشغيل على ماك أو لينكس

```bash
chmod +x start.sh
./start.sh
```

أو يدويًا:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

ثم افتح `http://localhost:8000/` في المتصفح.

<a id="phones"></a>
## 4) دخول الطلاب من هواتفهم

1. شغّل الموقع على حاسوب المعلم المتصل بشبكة المدرسة (Wi‑Fi).
2. عند التشغيل تظهر في النافذة السوداء روابط مثل:
   ```
   Students (Wi-Fi) : http://192.168.1.20:8000/play
   ```
3. افتح **شاشة العرض** `http://localhost:8000/display` على جهاز الإسقاط؛ سيظهر عليها **رمز QR** ورابط الانضمام تلقائيًا.
4. يتصل الطلاب بالشبكة نفسها، ويمسحون رمز QR بكاميرا الهاتف، ثم يختارون: الصف ← الفصل ← الاسم.
5. يبقى الطالب مسجّلًا حتى لو حدّث الصفحة أو انقطع الاتصال لحظيًا.

> بعض شبكات المدارس تعزل الأجهزة عن بعضها (Client Isolation). إذا لم تفتح الهواتف الرابط، جرّب نقطة اتصال (Hotspot) من هاتف المعلم، أو اطلب من فني الشبكة السماح بالاتصال بين الأجهزة، أو انشر الموقع على Render (القسم 9).

<a id="password"></a>
## 5) كلمة مرور المعلم

تُحدَّد كلمة مرور لوحة التحكم بالترتيب الآتي:

1. متغير البيئة **`ADMIN_PASSWORD`** إن وُجد (مناسب للخوادم).
2. وإلا الملف **`app/admin_password.txt`** إن وُجد.
3. وإلا كلمة المرور الافتراضية: **`admin123`**.

**غيّر كلمة المرور الافتراضية قبل أول مسابقة** من: لوحة التحكم ← الإعدادات ← تغيير كلمة المرور (تُحفظ في `app/admin_password.txt`). تظهر في لوحة التحكم رسالة تنبيه صفراء ما دامت الكلمة الافتراضية مستخدمة.

نسيت كلمة المرور؟ احذف الملف `app/admin_password.txt` وأعد تشغيل الموقع، فتعود إلى `admin123`.

<a id="guide"></a>
## 6) دليل المعلم خطوة بخطوة

### أ) الفصول والأسئلة
1. ادخل إلى `/admin` ← تبويب **الفصول والأسئلة**.
2. أضف الفصول: اختر الصف وأرقام الشعب (مثلًا العاشر من 1 إلى 4 ينشئ 10/1 حتى 10/4).
3. اختر فصلًا من القائمة، واكتب **عدد الأسئلة** ثم «تطبيق العدد»، واملأ لكل سؤال:
   - نص السؤال، والإجابة الصحيحة، ومن خيار إلى ثلاثة خيارات خاطئة، والزمن بالثواني (5–120).
4. اضغط **حفظ الأسئلة**.
5. أدوات مساعدة:
   - **أسئلة تجريبية:** 15 سؤالًا جاهزًا للتجربة.
   - **استيراد من نص:** الصق أسئلة كثيرة دفعة واحدة (السؤال، ثم الصحيحة، ثم الخاطئة، وسطر فارغ بين الأسئلة).
   - **نسخ إلى فصول أخرى:** انسخ بنك الأسئلة إلى فصل أو أكثر.

> لكل فصل بنك أسئلة خاص به. تُخلط الخيارات تلقائيًا وبترتيب مختلف لكل طالب.

### ب) إنشاء مسابقة
تبويب **الدوري والجولات** ← اختر النوع، والاسم، والفصول المشاركة:
- **دوري خروج المغلوب:** حدّد عدد الأسئلة في كل مباراة وطريقة الاقتران (حسب الصف / قرعة عشوائية). تُضاف «تأهلات مباشرة» تلقائيًا إذا لم يكن العدد 2 أو 4 أو 8 أو 16…
- **مسابقات منفصلة للفصول:** يكفي اختيار الفصول.

تصبح المسابقة الجديدة **مفعّلة** تلقائيًا، ويمكنك التبديل بين المسابقات بزر «تفعيل».

### ج) يوم المسابقة
1. افتح `/display` على جهاز الإسقاط، واضغط **ملء الشاشة**، ثم **بدء الافتتاح** (عدّ تنازلي واحتفال).
2. في لوحة التحكم ← **التحكم المباشر**:

**دوري خروج المغلوب:**
| الخطوة | الزر |
|---|---|
| يدخل الطلاب إلى المباراة | **فتح المباراة** |
| تحقق من الأسماء واستبعد أي اسم غير صحيح | ✕ بجانب الاسم |
| انطلاق (عدّ تنازلي 3 ثوانٍ ثم السؤال للجميع في اللحظة نفسها) | **ابدأ المباراة** |
| تُكشف الإجابة تلقائيًا عند انتهاء الوقت أو إجابة الجميع، أو مبكرًا | **كشف الإجابة الآن** |
| السؤال الذي يليه | **السؤال التالي** |
| بعد آخر سؤال: الفائز يتأهل تلقائيًا | **عرض النتيجة النهائية** ثم **إغلاق شاشة النتيجة** |

أزرار أخرى: **إنهاء واعتماد النتيجة** (إيقاف المباراة واحتساب الأسئلة المكتملة)، **إلغاء المباراة** (حذف نقاطها)، **فوز …** (تحديد الفائز يدويًا، مثلًا عند التعادل)، **إعادة ضبط** (إعادة لعب مباراة).

**مسابقات منفصلة:** حدّد الفصول ← **فتح الفصول المحددة** ← **بدء جميع الفصول المنتظرة**. تنتهي مسابقة كل فصل تلقائيًا عندما ينهي جميع طلابه، أو بزر **إنهاء الآن**. زر **إعادة ضبط** يحذف نتيجة الفصل لإعادتها.

**شاشة العرض:** اختر ما تعرضه: تلقائي، الانضمام، لوحة الصدارة، الشجرة/الترتيب، الشعار.

### د) الإحصائيات
أفضل الطلاب، والأسئلة الأصعب (أقل نسبة إجابة صحيحة)، وترتيب الفصول، وسجل المباريات، مع زرَّي «تصفير الإحصائيات» و«حذف جميع البيانات».

<a id="scoring"></a>
## 7) نظام النقاط

### دوري خروج المغلوب
- الإجابة الصحيحة: `1000 × (1 − (زمن الإجابة ÷ زمن السؤال) ÷ 2)` مقرّبة، أي بين 500 و1000 نقطة بحسب السرعة.
- مكافأة السلسلة: `min(السلسلة − 1، 3) × 100` (حتى 300 نقطة إضافية للإجابات الصحيحة المتتالية).
- الإجابة الخاطئة أو عدم الإجابة: 0، وتنقطع السلسلة.
- **نتيجة الفصل = متوسط نقاط طلابه** (فلا يؤثر عدد الطلاب). عند التساوي: الدقة، ثم متوسط سرعة الإجابة.

### المسابقات المنفصلة
- الإجابة الصحيحة: حتى **5 نقاط** بحسب السرعة: `5 × (1 − (الزمن ÷ زمن السؤال) ÷ 2)`، والخاطئة 0.
- ترتيب الفصول: متوسط النقاط من 5 لكل سؤال، ثم الدقة، ثم متوسط زمن الإنجاز.

<a id="fair"></a>
## 8) كيف يمنع الموقع الغش؟

- **الخادم وحده** يحسب الوقت والنقاط؛ لا يمكن التلاعب بالزمن من الهاتف.
- **لا تصل الإجابة الصحيحة إلى أي هاتف أو إلى شاشة العرض قبل كشفها**، وفي المسابقات المنفصلة لا تُكشف أبدًا (يعرف الطالب فقط إن كانت إجابته صحيحة).
- **ترتيب الخيارات مختلف لكل طالب**؛ فلا ينفع «اضغط الزر الثاني». وفي المسابقات المنفصلة **ترتيب الأسئلة مختلف** لكل طالب.
- **إجابة واحدة فقط** لكل سؤال، وتُرفض الإجابات بعد انتهاء الوقت.
- **لا انضمام بعد البدء** (إلا لمن كان في قائمة الانتظار)، ويمكن للمعلم تغيير ذلك.
- **لا يمكن للطالب الخروج أو تغيير فصله أثناء المباراة** (حتى لا يتهرب الطلاب الضعفاء من حساب المتوسط).
- **رصد مغادرة الصفحة:** إذا ترك الطالب صفحة السؤال (للبحث مثلًا) تظهر علامة ⚠ بجانب اسمه عند المعلم.
- **الاستبعاد:** يستطيع المعلم استبعاد أي اسم غير صحيح أو طالب دخل في فصل غير فصله.
- **حماية لوحة التحكم:** كلمة مرور، وقفل مؤقت بعد 8 محاولات خاطئة، وتنبيه عند استخدام الكلمة الافتراضية.
- **حماية تقنية:** تنظيف كل المدخلات، وسياسة أمان المحتوى (CSP)، ورفض الاتصالات من مواقع أخرى، وتحديد عدد الطلبات لكل جهاز.

<a id="render"></a>
## 9) النشر على الإنترنت عبر Render

1. ارفع المشروع إلى مستودع على GitHub.
2. ادخل إلى <https://render.com> ← **New** ← **Blueprint** واختر المستودع؛ سيقرأ الملف `render.yaml` تلقائيًا.
3. سيطلب منك Render قيمة **`ADMIN_PASSWORD`**: اكتب كلمة مرور قوية للمعلم.
4. بعد اكتمال النشر ستحصل على رابط مثل `https://difaf-alarabiya.onrender.com`. يظهر رمز QR على شاشة العرض بهذا الرابط تلقائيًا.

**تنبيهات الخطة المجانية:**
- الخدمة «تنام» بعد 15 دقيقة بلا زيارات، وتستغرق نحو دقيقة لتستيقظ. افتح الموقع قبل المسابقة بدقائق.
- **البيانات لا تبقى** عند إعادة تشغيل الخادم أو إعادة النشر في الخطة المجانية. لذلك:
  - نزّل **نسخة احتياطية** من «الإعدادات» بعد إدخال الأسئلة وبعد كل مسابقة، واستعدها عند الحاجة.
  - أو استخدم خطة مدفوعة مع قرص دائم (انظر التعليقات داخل `render.yaml`)؛ سيحفظ الموقع بياناته في `/data` تلقائيًا.

<a id="data"></a>
## 10) حفظ البيانات والنسخ الاحتياطي

- تُحفظ كل البيانات في ملف واحد: **`data/db.json`** (أو `/data/db.json` إذا وُجد قرص دائم على الخادم، أو المسار في متغير البيئة `DATA_DIR`).
- الحفظ تلقائي بعد كل تغيير بثانية، وبطريقة آمنة لا تُفسد الملف عند انقطاع الكهرباء.
- عند كل تشغيل تُحفظ نسخة من آخر بيانات سليمة في `data/db.backup.json`.
- من **الإعدادات** يمكنك **تنزيل نسخة احتياطية** أو **الاستعادة من ملف**.
- إذا توقف الخادم أثناء مباراة: تعود المباراة إلى «بانتظار اللعب» لإعادتها، وتُحفظ النتائج الجزئية للمسابقات المنفصلة مع علامة «توقف الخادم».

<a id="troubleshooting"></a>
## 11) حل المشكلات الشائعة

| المشكلة | الحل |
|---|---|
| `start.bat` يقول إن Python غير مثبت | ثبّت Python 3.12 مع تفعيل «Add python.exe to PATH» ثم أعد المحاولة |
| الهواتف لا تفتح الرابط | تأكد أن الهواتف على الشبكة نفسها، واسمح لـ Python في جدار الحماية، وجرّب Hotspot |
| ظهرت رسالة «جارٍ الاتصال بالخادم…» | الخادم متوقف أو انقطعت الشبكة؛ سيعاود الاتصال تلقائيًا عند عودتها |
| الطالب اختار فصلًا خاطئًا | قبل بدء المباراة: زر الخروج أعلى صفحته. بعد البدء: استبعده من لوحة التحكم ثم يخرج ويدخل من جديد |
| «بنك أسئلة الفصل فيه … سؤال فقط» | أضف أسئلة للفصل أو قلّل «أسئلة كل مباراة» في تبويب الدوري |
| لا يعمل الصوت على شاشة العرض | اضغط أي زر على الشاشة مرة واحدة (المتصفحات تمنع الصوت قبل أول ضغطة) |
| المنفذ 8000 مستخدم | شغّل يدويًا بمنفذ آخر: `--port 8080` |

<a id="dev"></a>
## 12) للمطورين

**التقنيات:** Python 3.12 · FastAPI · python-socketio (ASGI) · qrcode · HTML/CSS/JavaScript بلا أدوات بناء · ملف JSON للتخزين.

```
app/
  main.py              الخادم: صفحات HTTP، وواجهات /healthz و/api/info و/api/qr، وأحداث Socket.IO، ومؤقت الخادم
  game.py              منطق المسابقات: الفصول، والدوري، والمسابقات المنفصلة، والنقاط، والإحصائيات
  auth.py              كلمة مرور المعلم وجلسات الدخول
  store.py             حفظ ملف JSON (مؤجل وآمن)
  util.py              تنظيف المدخلات وعناوين الشبكة
  sample_questions.py  الأسئلة التجريبية
  pages/               صفحات HTML
  static/              CSS وJavaScript والصور والخطوط ومكتبة Socket.IO
tests/                 اختبارات pytest
requirements.txt · start.bat · start.sh · render.yaml
```

**أحداث Socket.IO الأساسية:**
`player:join` · `player:answer` · `player:leave` · `display:join` · `admin:login` · `admin:password` ·
`class:create` · `class:delete` · `class:saveQuestions` · `class:copyQuestions` ·
`tournament:create` · `tournament:activate` · `tournament:delete` ·
`match:open` · `match:start` · `match:reveal` · `match:next` · `match:cancel` · `match:close` · `match:setWinner` · `match:reset` · `match:kick` ·
`classCompetition:open` · `classCompetition:start` · `classCompetition:finish` · `classCompetition:reset` ·
`display:set` · `display:opening` · `stats:reset` · `data:reset`

**الواجهات:** `GET /healthz` · `GET /api/info` (روابط الشبكة المحلية) · `GET /api/qr?u=...` (رمز QR بصيغة SVG) · `GET /api/classes` · `GET /api/admin/export` · `POST /api/admin/import`

**تشغيل الاختبارات:**

```bash
pip install pytest
pytest -q
```

**الخط:** Cairo (رخصة SIL OFL، مضمّن في `app/static/fonts`). **مكتبة الاتصال:** Socket.IO 4.8.1 (رخصة MIT).
